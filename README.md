# 喫煙所マップ

喫煙所の位置を地図で探すための PWA です。**20歳未満の方は利用できません。このマップは喫煙をすすめるものではありません。**

公開URL: https://nerorisaia.github.io/smoking-map/

## 特長

- 全国の喫煙所データ（約1,300件）をアプリに内蔵しています。一度開くと端末に保存され、通信が弱い場所でも地点を表示できます（地図画像は通信が必要です）。
- 「紙巻き可」「加熱式のみ」「屋内」で絞り込めます。元データに種別がない地点は「種別不明」と表示します。
- 「今使える」は、利用時間のデータがある地点だけに表示します。
- 「現在地」「最寄り」で近くの喫煙所を探し、「ここへ行く」で Google マップの経路案内を開きます。
- 各地点に出典とデータ時点を表示します。

## データ

- OpenStreetMap（`amenity=smoking_area`）© OpenStreetMap contributors、ODbL 1.0
- 台東区「公衆喫煙所（区設置分）」CC BY 4.0
- 江東区「公共喫煙所一覧」CC BY
- 大阪市「マップナビおおさか オープンデータ」CC BY（喫煙所の行だけを使用）

詳しくはアプリ内の「出典」ページ（credits.html）をご覧ください。

- 掲載しているのは上記データにある地点だけです。データが無い地域には地点がありません。
- 情報が古い場合があります。現地の表示・各自治体のルールに従ってください。
- 路上喫煙禁止区域は表示していません。
- CLUB JT の喫煙所情報は含まれていません（「CLUB JTで見る」は外部サイトへのリンクです）。

## ライセンス

- 地点データ（data/smoking-jp.json）の OpenStreetMap 由来部分は ODbL 1.0 に従います。
- 自治体データ由来部分は、各自治体の CC BY の条件に従い出典を表示しています。
- 地図表示ライブラリ Leaflet（BSD-2-Clause）を vendor/leaflet に同梱しています。
